# WDM-LHM

Research software for diagnosing and, only where justified, combining information from the BRO Model Grondwaterspiegeldiepte (WDM), transient LHM/MODFLOW simulations, and groundwater monitoring time series.

## Project status

**Development / Status A-light bootstrap.** The repository separates scientific theory, conceptual model, formal model, implementation, data lineage, and qualification evidence. No statistical correction or WDM-conditioned product is considered a physically consistent LHM/MODFLOW state unless explicitly demonstrated.

## Current workstream

TS01–TS06 provide paired time-series diagnostics, multiwell observation operators, regime and process diagnostics, real-data admission, and BRO/PDOK ingest. See `docs/STATUS_A_LIGHT.md` and `docs/qualification/` for the qualification boundary.
