# Roadmap

## Current admitted development baseline

TS01–TS06 establish diagnostic analysis, real-data admission and public BRO/PDOK ingestion.

## Next scientific gate

**Freatic monitoring-tube screening.** Establish a qualified, transparent method for deciding which BRO monitoring tubes can represent the freatic groundwater table for WDM/LHM comparison. See `docs/qualification/FREATISCH_SCREENING_REQUIREMENTS.md`.

## After freatic screening

1. build a pilot observation bundle for one hydrologically varied study area;
2. reconstruct WDM/LHM lineage for selected wells;
3. bind the observation bundle to one explicit LHM/MODFLOW run;
4. pass TS05 admission;
5. execute TS01–TS04 on train/development/held-out groups;
6. only then decide whether WDM conditioning, residual post-processing or physical recalibration deserves a new workunit.
